# GeoMedic

Aplicación web para conectar pacientes con médicos, consultar horarios disponibles y reservar citas presenciales o mediante videollamada.

## Descripción

GeoMedic es una plataforma donde los usuarios pueden registrarse como médicos o pacientes.

Los médicos pueden completar su perfil profesional, indicar su especialidad, configurar su disponibilidad y consultar las citas reservadas.

Los pacientes pueden buscar médicos, consultar sus horarios disponibles y reservar citas presenciales o por videollamada.

## Funcionalidades

- Registro de médicos y pacientes.
- Inicio de sesión.
- Autenticación mediante JWT.
- Perfil profesional del médico.
- Configuración de horarios disponibles.
- Búsqueda de médicos por especialidad y ubicación.
- Reserva de citas.
- Consulta de citas próximas y pasadas.
- Cancelación de citas.
- Notificaciones de confirmación.
- Videollamadas.
